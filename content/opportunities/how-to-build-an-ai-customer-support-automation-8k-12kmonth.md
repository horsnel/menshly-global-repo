## The Workflow: Step-by-Step With Every Shortcut

### Step 1: Spin Up the Technical Backbone (4–6 hrs)

Start with a clean hosting foundation. Spin up a VPS on Hostinger for just $3.99/month. Pick the “Business” plan, 2 GB RAM, 50 GB SSD. Point a custom domain you’ll register through Hostinger for $0.99/year. SSH into the server and install Nginx, Node.js, and Docker. With Docker you can keep every micro‑service isolated—no more “it worked on my machine” headaches.

Pull the pre‑built ChatGPT integration container from Docker Hub. Configure the API key in a `.env` file:

```
OPENAI_API_KEY=sk-xxxxxx
MODEL=gpt‑4o
```

Set the prompt template in `/app/prompts/support.yaml`. This file will hold the core guidelines for all replies. Use a 200‑token context window to keep the bot snappy. Test the container locally with `docker run -p 3000:3000 mychatgpt:latest` and send a quick curl request:

```
curl -X POST http://localhost:3000/respond \
  -H "Content-Type: application/json" \
  -d '{"message":"I can’t log in to my account"}'
```

If everything returns a natural‑sounding response, you’re ready to expose the endpoint behind a reverse proxy. Add a simple Nginx block:

```
server {
    listen 443 ssl;
    server_name support.yourdomain.com;

    ssl_certificate /etc/ssl/fullchain.pem;
    ssl_certificate_key /etc/ssl/privkey.pem;

    location / {
        proxy_pass http://localhost:3000;
    }
}
```

**HACK:** Instead of paying for a dedicated load balancer, use Make.com to route traffic from a subdomain to your container. Make.com’s “HTTP Request” trigger can sit in front of your Nginx, and you’ll get free 15‑minute intervals for every 1,000 requests.

### Step 2: Build the Conversation Flow (3–5 hrs)

Open Notion and create a “Chatbot Flow” database. Each row is a state (e.g., “Greeting”, “Password Reset”, “Bug Report”). For each state, write a concise prompt and a set of 2–3 fallback responses. Example for Password Reset:

```
Prompt: "User says they forgot password. Ask for email, confirm domain, then give reset link."
Fallback 1: "I’m sorry, I can’t help with that."
Fallback 2: "Could you double‑check the email you used?"
```

Now, in ChatGPT, run a fine‑tuning job with the OpenAI “Chat Completions” endpoint. Upload your Notion database as a CSV, set `temperature=0.6`, `max_tokens=150`, `stop=["User:"]`. The fine‑tuned model will return a 200‑token output per request. The entire fine‑tune costs $15 for 50k training steps; you get 1 month of free requests per month. This saves you from paying $0.0004 per 1k tokens on the base model.

Integrate a voice layer with Vapi, which costs $0.0035 per minute at the Basic tier. Create a “Password Reset” voice script in the Vapi console. Map the same prompt you used for text; Vapi will synthesize a natural‑sounding voice using ElevenLabs, whose base pack is $15/month. Vapi automatically tags the conversation for analytics.

Add a fallback to the flow: If the bot can’t answer after three attempts, hand off to a human. Use Zapier to create a “Support Ticket” in ActiveCampaign. Zapier’s free plan supports 100 single‑action Zaps per month; upgrade to $19/month for unlimited zaps. In the Zap, set the filter: “If attempts > 3, then create Ticket”. Add the ticket as an Activity in ActiveCampaign, assign it to a team member, and send an email via Klaviyo with a custom “We’ll get back to you” message.

**HACK:** Use Make.com’s “Delay” action to wait 30 seconds before sending the final fallback. This gives the bot a chance to re‑attempt without the user feeling ignored.
