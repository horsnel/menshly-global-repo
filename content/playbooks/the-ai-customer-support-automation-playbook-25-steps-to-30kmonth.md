## Procedure 1.1: Register Your Business Domain on Hostinger

1. **Open your web browser** and go to **https://www.hostinger.com**.  
   *You should see Hostinger’s homepage with a search bar at the top.*

2. **Click the button labeled** **“Domain Search”** located in the top‑navigation bar.  
   *The Domain Search page displays a text field “Search for a domain”.*

3. **Type your desired domain name** (e.g., `menshlyglobal.com`) into the search field and hit **Enter**.  
   *You should see a list of availability results, with a green check if the domain is free.*

4. **Do you see a green check next to your domain?**  
   *If yes, proceed to step 5.*  
   *If not, try a different TLD (e.g., `.net`, `.io`) or add a keyword until you find an available domain.*

5. **Select the domain by clicking the button** **“Add to Cart”** next to the free‑together‑with‑hosting option.  
   *The cart icon in the upper right corner should now show “1 item”.*

6. **Click the cart icon** (basket) and choose **“Proceed to Checkout”**.  
   *You will be redirected to the checkout page with a summary of the domain and optional hosting plans.*

7. **Choose a hosting plan** that includes free domain registration (e.g., “Basic Shared Hosting – $1.99/month”).  
   *Ensure the “Free Domain” checkbox is checked automatically.*

8. **Click the button** **“Continue”** at the bottom of the hosting plan selection.  
   *The billing page appears, showing the domain price ($12.99/year) and hosting price.*

9. **Enter your account credentials** or **click “Create an Account”** if you are new.  
   *If creating a new account, fill in: Email, Password, Confirm Password, and check “I agree to the terms”.*  
   *Do you see the “Create Account” form?*  
   *If not, refresh the page and retry.*

10. **Select the billing cycle** “Annual” for both domain and hosting.  
    *The total should now read `$13.99/month` (pro-rated for the first year).*

11. **Click the button** **“Proceed to Payment”**.  
    *You will be directed to the payment gateway.*

12. **Choose a payment method** (Credit Card or PayPal).  
    *If using credit card, enter: Card Number, Expiry Date, CVV, Cardholder Name, and Billing ZIP.*  
    *If using PayPal, you’ll be redirected to the PayPal login page.*

13. **Complete the payment**.  
    *You should see a confirmation screen with “Your domain has been registered” and a “Domain Management” link.*

14. **Do you see the “Domain Management” link?**  
    *If yes, click it. If not, return to the Hostinger dashboard and navigate to “Domains” → “My Domains”.*

15. **In the Domain Management dashboard, locate your new domain** and click **“Manage”**.  
    *The domain details page shows DNS records, Registrar lock, and WHOIS settings.*

16. **Activate domain privacy** by toggling the switch labeled **“Enable WHOIS Privacy”**.  
    *The switch should turn green, indicating privacy is active.*

17. **Set up DNS records** for your AI support service:  
    - **A‑Record**: Click **“Add Record”** → Type **“A”** → Host **“@”** → Value **`192.0.2.123`** (replace with your server IP) → TTL **`3600`** → **“Save”**.  
    - **CNAME** for `support`: Click **“Add Record”** → Type **“CNAME”** → Host **“support”** → Value **`ghs.googlehosted.com`** → TTL **`3600`** → **“Save”**.

18. **Verify DNS propagation** by running a command from your terminal:  
    ```bash
    nslookup menshlyglobal.com
    ```  
    *You should see the IP address `192.0.2.123` in the output. If you see “NXDOMAIN”, wait 15–30 min and retry.*

def support():
