## Procedure 2.2: Build Your First Make.com Automation Scenario

1. **Open your web browser** and navigate to https://www.make.com/en/.  
2. Click **Sign up** in the upper‑right corner.  
3. Enter your **email address**, choose a **password**, and click **Continue**.

   *Do you see a green “Account verified” banner? If not, check your spam folder or resend the email by clicking **Resend verification**.*  

5. Log in with your credentials.  
6. On the dashboard, click the **Create a new scenario** button (bold).  
7. In the scenario editor, click the **+ Add another module** button.  
8. Search for **Webhooks** in the module list and select **Webhooks > Custom Webhook**.  
9. Click **Add** and name the webhook **NewCopyRequest**.  
10. The editor will display the webhook URL (e.g., `https://hook.integromat.com/abcd1234`).  
    *Do you see the URL in the **Webhook URL** field? If not, click **Refresh**.*  

11. **Copy** the URL to your clipboard.  
12. Open a new tab and go to https://app.ai-writer.com/api.  
13. Click **Generate API Key** (button bold).  
14. Copy the displayed key to your clipboard.  
    *Do you see the key in the **API Key** field? If not, ensure you’re logged into the AI Writer dashboard.*  

15. Return to Make.com and add a new module. Search for **HTTP** and select **HTTP > Make a request**.  
16. In the module settings:  
    - **Method**: POST  
    - **URL**: `https://api.ai-writer.com/v1/generate`  
    - **Headers**: `Authorization: Bearer <paste your AI Writer key>`  
    - **Body type**: JSON  
    - **Request content**:  
      ```
      {
        "prompt": "{{1.Webhook.Payload.title}}",
        "model": "gpt-4o-mini",
        "language": "en",
        "tone": "professional"
      }
      ```  
      *Replace `{{1.Webhook.Payload.title}}` with the title field from the webhook.*  

17. Click **OK** to save.  
    *Do you see the module highlighted in green? If not, check the URL and API key.*  

18. Add another module: search for **WordLift** and choose **WordLift > Optimize**.  
19. In the WordLift module:  
    - **Action**: Optimize  
    - **Title**: `{{2.HTTP.Response.body.title}}`  
    - **Content**: `{{2.HTTP.Response.body.generated_text}}`  
    - **Language**: EN  
    - **SEO Level**: Advanced  
    - **API Key**: (enter your WordLift API key)  

20. Click **OK**.  
    *Do you see the WordLift module connected to the HTTP module? If not, drag the connector line.*  

21. Add a **Notion** module: search for **Notion** and select **Notion > Create a database item**.  
22. Connect your Notion account via OAuth (click **Add connection**).  
23. Choose the database **Copy Projects**.  
24. Map fields:  
    - **Title**: `{{2.HTTP.Response.body.title}}`  
    - **Content**: `{{3.WordLift.Response.optimized_text}}`  
    - **Status**: `Pending Review`  
    - **Client Email**: `{{1.Webhook.Payload.client_email}}`  

25. Click **OK**.  
    *Do you see the Notion module linked after the WordLift module? If not, ensure the database is selected.*  

26. Add a **Klaviyo** module: search for **Klaviyo** and choose **Klaviyo > Add/Update Contact**.  
27. Connect your Klaviyo account (OAuth).  
28. Set **Email** to `{{1.Webhook.Payload.client_email}}`.  
29. Add **Properties**:  
    - `copy_title`: `{{2.HTTP.Response.body.title}}`  
    - `copy_status`: `Generated`  

30. Click **OK**.  
    *Do you see all modules connected in a linear flow? If not, drag connectors to form a chain.*  

31. Test the scenario: click the **Run once** button.
